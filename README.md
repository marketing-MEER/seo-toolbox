# 🧰 SEO Toolbox

### Free, open-source SEO tools. One job per repo.

**16 of 64 tools live** · new tools added every day

---

Every tool is a small Python CLI that reads the exports you already have (Google Search Console, Ahrefs, Semrush, sitemaps, crawls), needs **no API keys**, and writes a **formatted HTML report** plus an **Excel file**. Each one is built on published SEO data from the [Neil Patel marketing stats library](https://neilpatel.com/marketing-stats/), so every check has a reason behind it.

Start here: **[seo-workhorse](https://github.com/marketing-MEER/seo-workhorse)**, an all-in-one CLI for audits, keyword clustering, redirects and GSC quick wins.
